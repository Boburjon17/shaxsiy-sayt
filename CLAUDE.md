# Demosite — shaxsiy vizitka sayt

## Loyiha
- Sodiqov Boburjonning shaxsiy sayti: biznes jarayonlarini avtomatlashtirish (AppSheet, Google Workspace) va IT infratuzilma mutaxassisi.
- Maqsad: mijozlar (klinikalar, savdo korxonalari) xizmatlarni ko'rib, Telegram yoki telefon orqali bog'lanishi.
- Sayt matni o'zbek tilida. Foydalanuvchi bilan ham o'zbek tilida, sodda gaplash.

## Uslub
- Ranglar: fon #F8F4EE, matn #2B2522, yordamchi matn #6B5F56, asosiy rang ochroq yashil #3A9D5D.
- Ranglar `style.css` boshidagi o'zgaruvchilarda turadi. Yangi rangni o'sha yerga qo'sh, kod ichiga to'g'ridan-to'g'ri yozma.
- Tungi rejim bor: har bir yangi element ikkala rejimda ham yaxshi ko'rinishi kerak.
- Ohang: professional, ishonchli va qisqa. Ortiqcha bezak va reklama gaplari kerak emas.
- Ikonkalar oddiy, chiziqli SVG.

## Texnik chegaralar
- Sayt bitta sahifadan iborat: `index.html`, `style.css`, `script.js`. Yangi sahifa yoki fayl qo'shishdan oldin so'ra.
- Faqat oddiy HTML, CSS va JavaScript. Framework, kutubxona va build vositalari kerak emas.
- Rasmlar `images/` papkasida turadi (hero rasmi: `images/rasm.jpg`).
- Sayt telefonda ham to'g'ri ko'rinishi kerak.
- Bu faylga yoki kodga parol, API kalit, token yozilmaydi.

## Ish qoidalari
- Katta o'zgarishdan oldin qisqa reja ko'rsat va tasdiqni kut.
- Kichik qadamlar bilan ishla: bir safarda bitta o'zgarish, keyin natijani ko'rsat.
- O'zgarishdan keyin saytni brauzerda tekshir (lokal server: `.claude/launch.json`).
- Ma'lumot yetishmasa (loyiha, matn, rang), o'zing to'qima: so'ra yoki namuna ekanini aniq ayt.
